# Tinkerway

A workshop for a maker, or a small team.

You type whatever is in your head. The app keeps the context, turns it into an experiment or a project, and hands the next piece to a person or to a tool you already use. The workshop is a folder of files you own.

## Open source

The app is open source. It reads personal notes and context, so it cannot be a black box.

1. Your data stays yours, and it is backed up.
2. There are very few features. The product is the backbone: a platform where you connect the tools you already use and build your own home base.
3. This is experimental. Features that get added will change or be updated quickly.
4. The project is opinionated. Pull requests are not merged at random.
5. Contributions are welcome, especially from people who are better at a piece of this. Good work is not discarded at random.
6. A future version might become closed source if security, or running the project, gets out of hand and stops being peaceful to live with.
7. This list will grow, so the project stays sane to maintain.
