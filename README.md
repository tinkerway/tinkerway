# Tinkerway

A workshop for a maker, or a small team.

You type whatever is in your head. The app keeps the context, turns it into an experiment or a project, and hands the next piece to a person or to a tool you already use. The workshop is a folder of files you own.

## Open source

The app is open source, because it is personal. Notes, context, and everything else live here, so it can't be a black box people trust blindly.

1. Your data is always yours, and it is backed up securely.
2. This is experimental software. I tinker with my curiosity, so things may change rapidly. Features that get added will be changed or updated quickly.
3. There are very few features. Not much of a feature at all, other than the backbone: a platform where you connect tools and build your own home base.
4. A future version might become closed source if it gets out of my hands to manage. Security, or any other problem I can't manage, when it affects living peacefully.
5. Very opinionated, so I may not merge pull requests at random.
6. I still hope people more talented than me will contribute, so I won't discard work at random either.
7. This may become a running list of disclaimers like this one, to protect against chaos (in a good way) and to keep some sanity for myself while managing an open source project.
